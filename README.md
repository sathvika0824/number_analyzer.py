🧮 Number Analyzer (Python)
📌 Description

Number Analyzer is a beginner-friendly Python project that analyzes a given number using common mathematical and logical checks.
This project is built to strengthen DSA fundamentals, problem-solving skills, and Python basics.

It is designed as a learning project, focusing on logic clarity rather than advanced optimizations.

🚀 Features

The project can analyze numbers for the following properties:

✅ Palindrome Number

🔄 Reverse Integer

🔢 Power of Two

🔺 Ugly Number

😊 Happy Number

📊 Count Prime Numbers (using Sieve of Eratosthenes)

🛠️ Technologies Used

Python 3

Basic Data Structures & Algorithms (DSA)

Mathematical Logic

▶️ How to Run

Clone the repository:

Navigate to the project folder:

cd number-analyzer

Run the program:

python number_analyzer.py
